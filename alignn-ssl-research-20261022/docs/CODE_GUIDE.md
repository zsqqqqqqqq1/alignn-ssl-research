# 模型与代码导读

## 可选自监督

统一入口先读取 所选 `configs/formal_*.json`。false时由 `supervised_run.py` 调度，
`OriginalSupervisedModel`持有单个原始ALIGNNAtomWise，直接调用其forward，
全部参数允许训练，不经过MaskedModel和FrozenDownstream。
true时仍按下面原有流程执行。

## 一次自监督运行经历什么

1. `run_formal_wsl.sh` 选用当前环境的 Python，调用 `run_formal_display.py`，启用简洁显示和单进程加载。
2. `run_formal.py` 读取三组 JSON，检查组间差异，创建实验锁，核对或建立 `protocol.json`，准备固定数据。
3. 对所选组依次执行 `pretrain` 和 `downstream`。已有完整完成标记时跳过，存在有效断点时恢复。
4. `ssl_alignn/runner.py` 负责训练、验证、保存与选模。完成下游后，加载最佳验证模型产生最终测试结果。
5. 两组 Z64 都结束后，`ssl_alignn/report.py` 核对数据、冻结权重和测试预测，再进行配对比较。

## 数据与图

`data.py: build_graph()` 调用原版 `Graph.atom_dgl_multigraph`，从 POSCAR 得到原子图与线图。原子种类来自结构文件的元素，92 维 CGCNN 特征通过上游/JARVIS 的元素特征表获取，不是从形成能标签拟合得到。

- `x`：每个原子的 92 维特征。
- `distance`：图边对应的原子间距离，模型将其展开为 80 维 RBF。
- `angles`：线图的键角余弦，展开为 40 维 RBF。
- `period / group`：重构标签，分别为扩展周期表的行号与列号。
- `pair_ids`：同一物理键的正反向及重复边共用标签，保证一起遮蔽。

进入模型前，图对象上的原子特征、原始坐标向量等字段被清空，模型显式接收需要的张量，减少被掩码信息通过旧图字段绕过的风险。角度和拓扑仍然可见，不能声称整个几何信息完全隐藏。

`CrystalData` 按结构哈希验证数据，按图配置及代码指纹组织缓存。监督阶段才读取形成能标签。单进程适配器只改变加载方式，不改变样本次序、掩码或优化器。

## 三种维度的含义

| 字段 | 正式值 | 作用 |
|---|---:|---|
| `model.dim` | 256 | 消息传递隐藏状态的宽度 |
| `model.embedding_features` | 64 | 距离/角度嵌入 MLP 的中间宽度 |
| `model.z_dim` | 64 或 256 | 预训练编码器交给下游的原子表示宽度 |

`hidden=256` 与 `Z=64` 并不冲突：主干先学习 256 维隐藏状态，再通过预训练期间学习的线性层压缩至 64 维。

## 预训练模型

`model.py: MaskedModel` 使用上游 ALIGNN 组件构建 `Backbone`，随后添加原子投影和重构头。保留本地上游的原子图再线图执行顺序，不重新实现卷积层。

`sample_masks()` 在每个晶体内抽取约 15% 原子与物理键，至少一个。固定种子控制抽样，验证掩码按固定验证批次种子生成。

`inputs()` 先计算距离 RBF，然后替换被遮蔽部分。两种 mask：

- `learnable` 使用 `nn.Parameter`，原子向量 92 维，边向量 80 维，零初始化后会接收梯度。
- `zero` 使用 buffer 保存固定零值，不作为优化参数。

原子隐藏表示经过 `atom_projection` 后输入两个分类头：行号 9 类、列号 18 类。边隐藏表示输入距离分类头：80 类。真实距离以最近 RBF 中心的索引作为类别。

损失为三个交叉熵的加权和，正式权重均为 1。**预训练选择验证重构总损失最低的编码器，不以形成能 MAE 选取。**

## “9 类行号”的物理解释

`labels.py` 首先读取 JARVIS 的 `row` 和拼写为 `coulmn` 的属性，只有缺失或越界时使用显式兜底表。第 8、9 行表示扩展周期表中单列展示的 f 区。它们不是物理第 8、9 周期；对应列号也不能都解释为常规物理族号。

这套标签只用于自监督重构监督信号，不改变上游的 92 维 CGCNN 输入特征。

## 冻结后的下游网络

`FrozenDownstream` 持有两部分：

1. 已预训练的编码器及原子投影。设置 `requires_grad_(False)`，始终保持 `eval()`，前向在 `torch.no_grad()` 内进行。
2. 新建的下游 `Backbone` 与形成能回归头。接收 Z、距离及键角，在监督训练中更新参数。

Z64 经过新的上游 `MLPLayer` 映射为 hidden256；Z256 直传组则使用 Identity。最终对原子表示图池化并回归一个每原子形成能值。

冻结的目的，是测量固定预训练表示对下游的作用，同时限制预训练参数变化；这是一种实验设计，不保证优于端到端微调。

## 微批与优化器步

正式 batch=64，microbatch=32。`backward_batch()` 将一个有效批次分块反向传播，再执行一次 optimizer.step。监督损失按材料数量加权；预训练损失按实际被遮蔽原子/边数量加权，不能简单把每个微批损失除以 2。

当前上游实际使用LayerNorm，虽然部分变量名或注释仍写bn/BatchNorm。
不能把批次运行统计变化当作这里梯度累积的差异来源；浮点累加次序仍可能造成数值差别。
恢复步数是优化器更新次数，不是微批次数。

## 断点、选模与测试

`state.py: atomic_save()` 使用同目录临时文件、flush/fsync 与原子替换来保存完整状态，避免异常处理时写入半步更新。即使有该机制，硬件或文件系统故障仍可能损坏文件，所以重要实验结果仍应独立归档。

`runner.py` 比较验证指标，保存最佳权重的独立副本。预训练和监督的选模指标不同。`training_state.pt` 恢复最近进度，`best.pt` 保存最佳验证模型。最终测试使用最佳下游模型，不使用最后一轮模型替代。
